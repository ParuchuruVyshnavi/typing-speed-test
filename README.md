# ⌨ Advanced Typing Speed Test

An interactive Typing Speed Test web application built using HTML, CSS, and JavaScript.

## 🚀 Features

* User Login & Register System
* Difficulty Levels

  * Easy
  * Medium
  * Hard
* Time Limit Selection
* Real-Time WPM Calculation
* Accuracy Tracking
* Mistake Counter
* Auto Next Sentence Loading
* Progress Bar
* Last 5 Seconds Alert
* Keyboard Highlight Effect
* High Score Storage using LocalStorage
* Dark / Light Mode
* Fully Responsive Design

# ▶ How to Run

1. Download or clone the project
2. Open the project folder in VS Code
3. Install Live Server extension
4. Right click `index.html`
5. Click **Open with Live Server**
